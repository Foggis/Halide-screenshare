# Halide | Automatic screenshare tool for Minecraft java edition

## About
Halide screenshare tool is meant to detect cheating players locally instead of server sided because modules such as auto clicker, aim assist, auto jump reset etc is super easy to bypass on all anticheats.

## Features
- None because this is basically just a base for now...


# Why use this over something like Echo.ac?
Most Minecraft screensharing tools are either not FOSS, suck, or are not cross-platform.


## How do i use it?
- Download the compiled file from [releases page](placeholder.com).
- Double click the jar file, if it doesent launch try to open a cmd in that dir and type ```java -jar HalideScreenshareTool.jar``` and press enter.
